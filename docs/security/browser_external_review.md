# Security review: real-browser access to external sites (NOT APPROVED)

**Review date:** 2026-10-12  
**Repository baseline:** `mammut001/Conveyor`, `main` at `f370c47522c5907d33dee1793b18392546ffa24f` (PRs #110 and #111).  
**Decision:** **NO-GO for any external website, authenticated session, upload, download, transaction, or final submit.** This is an architectural threat review and a set of *future release gates*, not an authorization or implementation. Keep `CONVEYOR_REAL_BROWSER` default-off. Passing fixture tests does not imply that untrusted internet content is safe.

## 1. Scope, trust boundaries, and current behavior

The current `LocalPlaywrightBrowser` is a test-oriented Chromium adapter, not a general-purpose provider. It is opt-in, manually supplied with a loopback fixture origin, not registered with WebRuntime/production workflow engine, and constrained to three checked-in HTML pages. `execute_fixture_plan` remains in-memory; `execute_workflow_browser_plan` accepts only the exact `FixtureBrowser` or `LocalPlaywrightBrowser` types and an explicitly running browser workflow checkpoint ([`workflow_browser_bridge.py:1-5`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_bridge.py#L1-L5), [`workflow_browser_bridge.py:90-105`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_bridge.py#L90-L105), [`workflow_browser_bridge.py:204-232`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_bridge.py#L204-L232)). The browser plan parser accepts only the `visitor600_mock` fixture, bounded synthetic values and five known action kinds, not arbitrary URLs, selectors, JS, credentials, file paths, or uploads ([`workflow_browser_contract.py:14-21`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_contract.py#L14-L21), [`workflow_browser_contract.py:45-99`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_contract.py#L45-L99)).

Relevant boundaries: user/operator -> workflow plan -> browser bridge/journal -> Playwright context -> fixture HTTP server; and separately operator -> Web/GUI Human Takeover lease -> noVNC/X11 desktop. Future third-party pages would be **adversarial data**, not instructions, trusted action plans, proof of user consent, or authority to weaken the browser policy.

## 2. External-site attacker model

**Assets:** operator intent and approvals; local machine/network and internal endpoints; authenticated cookies, tokens, passwords, PII and form values; funds/accounts and irreversible actions; plan/journal integrity; host desktop and CDP control channel.  
**Adversaries:** hostile site operator or compromised CDN/dependency, injected page/iframe/ad/widget, malicious redirect destination, compromised page script/service worker, untrusted page text crafted to instruct an LLM, and attacker-controlled network endpoints (including DNS/rebinding). Assume a page can mutate rapidly and behave differently during inspection and interaction.  
**Security invariant:** external-origin page content is untrusted input. It must never authorize browser capabilities, change a workflow’s approved targets, access host secrets or privileged browser control, or trigger side effects outside an explicitly approved human decision.

| Threat / abuse path | Impact and required future control | Status today |
| --- | --- | --- |
| Prompt injection via page text, titles, ARIA attributes, hidden nodes or responses | Page can say “ignore prior instructions”, request secrets, forge approval, or induce tool calls. Treat all page text as tainted, segregate from system/operator directives, restrict tool-call policy server-side, log attempted instruction crossings without storing secrets; red-team with malicious page variants. | **Not addressed for external sites**: current adapter uses fixed fixture actions, not an LLM-operated external page. |
| Credential or PII exfiltration via fetch, form/image beacon, WebSocket, WebRTC, DNS or redirects | Enforce process/network egress and DNS/IP/port policy, not JS hooks alone; exclude internal/metadata IP ranges and unsafe schemes; redact event logs; block credentials in agent-visible context. | Fixture requests/WS/RTC guarded; **no general internet egress isolation or credential-vault contract**. |
| Unintended form submits, purchases or account changes (including GET-side effects) | No autonomous irreversible action; deny all mutating methods and action-like links; independent human review bound to exact origin, action, consequence and fresh page state; server/network enforcement and idempotent reconciliation. | Synthetic fixture clicks only; sensitive submit controls and non-GET intercepted, **not a real transaction approval system**. |
| Drive-by downloads and uploads | Disable browser downloads, file chooser and file-system permissions; block request bodies/multipart and file input; verify no file written/exfiltrated. | Downloads denied, file inputs rejected; **no safe external upload/download pathway**. |
| Cross-origin navigation, subresources, redirects, popups and opener manipulation | Per-navigation and per-request allowlist; DNS pin/revalidation across redirects; schemes, ports, IP ranges and top-level vs subresource distinctions; no surprise origin grant. | Fixed loopback/three pages, zero redirects, popup deny; **not a reusable external-origin policy**. |
| Cookie/session reuse, browser cache, localStorage and service-worker persistence | One-shot isolated no-auth profile by default, no imported cookies/storage state, separate per-task contexts, verified cleanup; authenticated mode requires separate explicit review. | New private context and service-worker block; **no comprehensive durable-profile/session isolation contract or authenticated session support**. |
| Clickjacking, overlays, invisible/offscreen controls and DOM swaps | Before-action hit testing, visible target identity/origin binding, overlay/iframe checks and atomic revalidation; fail closed on mutation or mismatched destination. | Fixture checks target visibility and href; **not sufficient for hostile dynamic pages**. |
| CDP/debug-port exposure, injected JS and browser process compromise | Never expose CDP port or authenticated debugging endpoint on any public interface; localhost-only IPC, OS sandbox/account boundary, no privileged host filesystem, no arbitrary evaluate from untrusted data; isolate DevTools secrets and terminate context on errors. | Ephemeral internal CDP DOM inspection only; **no reviewed external-browser process/network attack boundary**. |
| Stale checkpoint, takeover race, double submit after crash | Bind approval and journal to immutable action, site and session identity; distributed lease/exclusive ownership; uncertain outcome -> reconciliation, never speculative replay. | Fixture journal/CAS semantics exist, but **not bound to real-site outcomes or the GUI takeover lease**. |

## 3. Residual gaps / reasons this is NOT an external-site safety claim

1. **Snapshot-only checks and time-of-check/time-of-use:** `_check()` calls DOM and CDP inspection before/after `apply` and during readback, but is not an atomic network/DOM mutation interlock. Page timers, navigation, event handlers and transient controls may act between checks; GET can itself change remote state. The JS scanner also differs from the CDP scanner in coverage (e.g. implicit submit button defaults). Require continuously enforced network policy plus event/mutation and target-time guards, not merely more polling ([`workflow_browser_playwright.py:225-283`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_playwright.py#L225-L283), [`workflow_browser_playwright.py:318-359`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_playwright.py#L318-L359), [`workflow_browser_guards.py:89-95`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_guards.py#L89-L95)).
2. **Iframe-grabbed APIs / alternate realms:** init scripts aim to run in every page/frame, and checks reject frame counts other than one; however, objects/methods obtained from an iframe `contentWindow`, newly-created `about:blank`/`srcdoc` realms, detached frames or prototype/instance-property shadowing need adversarial tests. Frame-count checks at checkpoints are not a proof against transient frames. Treat bypass as *a class to test*, not as an already verified exploit ([`workflow_browser_playwright.py:264-271`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_playwright.py#L264-L271), [`workflow_browser_guards.py:13-43`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_guards.py#L13-L43)). Playwright's own `navigator.serviceWorker` no-op can shadow the prototype override; current test correctly asserts zero registration rather than a required sticky reason ([`tests/test_workflow_browser_guards.py:199-222`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/tests/test_workflow_browser_guards.py#L199-L222)).
3. **Origin normalization nit:** `urlsplit` plus exact `netloc`/prefix comparison intentionally rejects many equivalent spellings, but no dedicated external-domain canonicalization/punycode/trailing-dot/IPv6/IDNA/percent-encoding policy is present. Reuse of `localhost` (name resolution) is not a DNS/SSRF defense. Define a single canonical site-identity routine and test ambiguity, redirects and resolved IPs before any external allowlist ([`workflow_browser_playwright.py:56-71`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_playwright.py#L56-L71), [`workflow_browser_playwright.py:194-204`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_playwright.py#L194-L204)).
4. **Not a live egress sandbox:** intercepted Playwright HTTP and WS requests are not a process-wide network firewall. Validate DNS, UDP, browser background traffic and all worker/frame/URL API avenues against a network-namespace/proxy capture, including zero reachable unapproved sockets ([`workflow_browser_playwright.py:100-113`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_playwright.py#L100-L113), [`workflow_browser_playwright.py:206-223`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_playwright.py#L206-L223)).
5. **Missing real-site consent and instruction boundary:** no per-domain approval record, signed action-intent digest, prompt-injection trust separator, persistent session ownership/expiry, real-site after-action proof, or approval on mutation/submission. Existing contract intentionally forbids them ([`workflow_browser_contract.py:45-99`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_contract.py#L45-L99), [`workflow_browser_bridge.py:204-276`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_bridge.py#L204-L276)).
6. **Takeover is not yet an end-to-end browser lease:** the browser workflow guard detects `waiting_for_human` in `WorkflowStore`, while `HumanTakeoverStore` governs desktop ownership. Before external pages, tie both to a single fail-closed lease/idle barrier and verify post-handoff revalidation. Never capture password, OTP, CVV, clipboard, or payment screenshot during handoff ([`workflow_browser_bridge.py:234-252`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_bridge.py#L234-L252), [`web_takeover.py:239-265`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/web_takeover.py#L239-L265), [`human_takeover.py:291-298`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/human_takeover.py#L291-L298)).
7. **CDP itself is privileged:** the CDP `pierce` scanner is useful defense in depth, not a containment mechanism against browser compromise, inaccessible targets or a debugger reachable by a different user/process ([`workflow_browser_guards.py:115-135`](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/workflow_browser_guards.py#L115-L135)).

## 4. Phased release gates (every phase is **disabled** until all tests pass)

**Default release rule:** Gate `G0` is the only approved state at this baseline. Every subsequent gate requires (a) a new reviewed implementation PR, (b) documented user consent and target scope, (c) its **own** acceptance matrix in CI against controlled test domains and instrumented network capture, (d) passing all earlier gates, and (e) independent security sign-off. The user-facing flag alone is never the permission check. No live third-party site is used for security tests without the site owner's permission.

### G0 — Current localhost fixture only (remain enabled only on explicit local opt-in)

- **Capability:** keep `CONVEYOR_REAL_BROWSER` default-off; if explicitly enabled, exactly the checked-in loopback pages and mock contract. No external site or general browser provider.
- **Required acceptance tests:** with the flag unset, every real-browser construction/dispatch fails; with flag on, real Chromium fixture flow, byte attestation, GET-only, redirect/cross-origin, WebSocket/Worker/ServiceWorker/WebRTC, `document.write`, CDP closed-shadow, secret-free journal, crash uncertainty and human checkpoint regressions all pass. `CONVEYOR_REQUIRE_REAL_BROWSER=1` must **fail** if Playwright/Chromium unavailable, never skip. Preserve real socket listener assertions with zero connections. Fail closed on missing interception/CDP.
- **Evidence:** existing [adapter tests](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/tests/test_workflow_browser_playwright.py), [guard tests](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/tests/test_workflow_browser_guards.py) and [required CI job](https://github.com/mammut001/Conveyor/blob/f370c47522c5907d33dee1793b18392546ffa24f/.github/workflows/ci.yml#L96-L117); run and record results for the candidate commit, not simply cite past green checks.

### G1 — Explicitly approved, **read-only**, unauthenticated per-domain allowlist

- **Capability:** one selected HTTPS domain/port, one bounded session and task approved through an operator UI; no authentication, no agent-created browser-profile reuse, no POST/PUT/PATCH/DELETE, no file I/O, popups, downloads, uploads, forms, purchases, or final submits. Keep all non-approved origins and subresources blocked by default. New isolated ephemeral browser profile with empty cookie/storage state; no secret-bearing host mounts.
- **Must implement first:** centrally canonicalized origin + resolved-address allowlist, DNS/rebinding/redirect guard, explicit domain/task/TTL approval ledger, browser-wide network egress deny enforced outside page JS, safe read-only navigation and page-content taint boundary, bounded requests/time and redacted **egress log** (timestamp, task, approved domain, method, outcome, denial code; no credentials, query strings or bodies); hard kill switch and automatic profile deletion.
- **Acceptance tests (all mandatory):**
  1. Unapproved domain, wildcard lookalike, mixed case/IDNA/trailing dot, IPv4/IPv6 literal, numeric/encoded host, userinfo, non-HTTPS, port trick, scheme switch, open redirect, DNS rebinding, CNAME/internal/metadata IP and localhost pivot -> **zero unapproved outbound connections** at OS/proxy capture, denial audit recorded.
  2. HTTP methods other than GET/HEAD, even from JS, forms, `sendBeacon`, prefetch, navigation and iframe, -> zero server-observed state-changing requests; assert **GET endpoints with known side effects are not visited** unless explicitly marked safe by the domain policy. HEAD is only allowed after side-effect review.
  3. Cookie jar/storage/cache empty at start; two tasks with different users/domains cannot observe each other's state; no persisted profiles, service workers, downloads or host-file reads after session termination/crash.
  4. Prompt-injection corpus on controlled pages cannot expand allowlist, execute tools, request credentials or change workflow intent; no page text can be promoted to operator approval.
  5. HTTP(S), WS, WebRTC, worker/iframe and browser-background egress monitored from namespace: deny paths produce zero destination connections; egress/denial records redact tokenized paths, queries, POST bodies, PII and content. Forced logging/proxy failure blocks browsing.
  6. Expired/revoked approval mid-load immediately stops new requests and actions, closes context and fails closed; operator UI shows exact domain, scope and expiry.

### G2 — Bounded external-site browsing and DOM interaction, still **no writes**

- **Capability:** navigate and inspect approved read-only pages with tightly typed actions; no credential filling, form submission, uploads, click on purchase/account-change controls or browsing across domains without a *new* approval. No open-ended LLM-driven JS/evaluate or raw selector/URL injection.
- **Acceptance tests (all mandatory):**
  1. Create/remove iframes, `about:blank`, `srcdoc`, detached frames and use iframe-grabbed `fetch`/`WebSocket`/`RTCPeerConnection`/worker/`document.write` prototypes; attempt instance-property overrides and closed/declarative shadow roots. All unauthorized networking/DOM control creation is denied or the entire session is terminated **before** dangerous action/egress.
  2. Mutable DOM swaps, overlay/clickjacking, invisible and offscreen controls, nested frames, cross-origin frame content, link redirects and navigation races -> agent cannot click a different target/destination; action identity and origin revalidated immediately at execution.
